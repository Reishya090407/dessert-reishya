# MINI BITES - Dessert Shop E-Commerce 🧁✨

Web e-commerce murni (Vanilla Architecture) untuk toko dessert **MINI BITES** dengan tema visual pastel yang manis, responsif, dan interaktif. Proyek ini dibuat sebagai pemenuhan tugas pengembangan website e-commerce menggunakan teknologi dasar web (HTML, CSS, dan JavaScript).

## 🚀 Fitur Utama
* **Responsive Design:** Tampilan web otomatis menyesuaikan layar laptop maupun smartphone.
* **Dynamic Shopping Cart:** Keranjang belanja interaktif yang bisa menghitung jumlah barang dan total harga pesanan secara langsung (real-time).
* **WhatsApp Checkout:** Integrasi sistem order langsung terhubung ke nomor WhatsApp admin dengan format teks pemesanan otomatis.
